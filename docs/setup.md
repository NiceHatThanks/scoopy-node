# Setup

This guide will cover first-time setup of Scoopy Node with ESPHome and Home Assistant.

## Planned flow

1. Power the node over USB-C.
2. Join it to Wi-Fi using the initial provisioning flow.
3. Add the discovered ESPHome device in Home Assistant.
4. Confirm buttons and LEDs are working.
5. Apply any optional radar or I²C configuration.

Detailed provisioning instructions will be added once the V1 firmware flow is finalised.
