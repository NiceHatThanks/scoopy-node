# Hardware

Electrical design and manufacturing files for Scoopy Node.

- `kicad/` — editable KiCad project files
- `gerbers/` — fabrication-ready board outputs
- `bom/` — bill of materials and manufacturing exports
- `schematics/` — schematic PDFs and supporting exports

Release-specific manufacturing files should be tagged or placed in versioned release folders once hardware revisions are frozen.
